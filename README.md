Saya suka merancang aplikasi web yang menyelesaikan masalah nyata, bukan sekadar demo. Fokus saya ada di **full-stack JavaScript/TypeScript** dan **Laravel**, dengan produk yang sudah live di Vercel.

- Membangun marketplace, showroom, dan tools produktivitas mahasiswa

- Red ranger off-duty — kerjaannya tetap serius, profilnya boleh agak fun
